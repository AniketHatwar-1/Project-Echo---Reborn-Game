# PROJECT ECHO: Black Signal — Reborn

A standalone offline-capable 2D action-platformer prototype. 

can be played at https://anikethatwar-1.github.io/Project-Echo---Reborn-Game/

## Controls
- A/D or arrow keys: move
- Space / W / Up: jump
- Mouse: aim; hold left mouse button to fire
- E: interact with terminals, records, supplies and exits
- Q: switch between pulse pistol and arc rifle
- R: reload
- Esc: pause / resume
- Mobile touch controls are included.

## Modes
Story (balanced supplies and narrative), Iron Run (less ammo and harder enemies), Scout (reduced threat and increased health).

## Game contents
Six sectors, character dialogue, field records, maths / sequence / observation / logic terminals, two weapons, reload and ammunition management, enemy wind-up attacks, projectiles, hazards, checkpoints, health, pickups, score, boss encounters, procedural lighting and industrial scenery, sound effects, and local save data.

## Design / art note
The game uses original characters, locations, level layouts, and procedural pixel-art-inspired rendering. Level pacing borrows broad genre patterns found across classic action-platformers—combat arenas, vertical traversal, hazard runs, and puzzle locks—but does not reproduce another game's exact maps or assets. This is a playable indie foundation, not a commercial-scale Zombotron-equivalent art production.
